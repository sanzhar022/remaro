# REMARO — очистка товарных данных

Запуск: `npm run products:clean`. Необязательный аргумент: `--file "полный путь.xlsx"`.
Нужны зависимости проекта, Python с openpyxl и DATABASE_URL. Команда не поддерживает --apply.
База читается только в REPEATABLE READ READ ONLY транзакции, которая завершается ROLLBACK.

Результат: reports/product-import/Remaro_products_cleaned.xlsx.
Исходный Excel не изменяется; SHA256 проверяется до и после.
Трансформация выполняется дважды в памяти: сравниваются значения и идентификаторы, а не служебные ZIP-времена.

Шесть листов:
- READY — прошедшие существующий валидатор товары с реальной ценой и однозначной категорией.
- MISSING_PRICE — отсутствует реальная цена, других блокеров нет.
- MANUAL_REVIEW — нерешённая идентичность, бренд, категория или конфликт характеристики; может также отсутствовать цена.
- NEW_CATEGORY_CANDIDATES — предложения, ничего в БД не создаётся.
- EXCLUDED_DEMO — семь исходных демонстрационных строк.
- IMPORT_SUMMARY — итоговые счётчики и контрольные суммы.

На товарных листах сохранены 26 исходных колонок для совместимости с импортером.
Исходные номера строк, флаги и причины review находятся в комментариях ячеек A и Z, а также в cleanup-audit.json.
STOCK_NOT_PROVIDED и IMAGE_PENDING дополнительно записаны в Примечании.
Маркер [REMARO:MANUAL_REVIEW] блокируется существующим импортером, даже если остальные поля корректны.

## Восстановление колонок

Строки 992–1092 имеют отдельную раскладку. Таблица использует буквы исходного Excel:

| Поле назначения | Исходная колонка |
| --- | --- |
| Категория / подкатегория | A / B |
| Бренд | D |
| SKU | F |
| Slug | E |
| Название | G |
| Цена | I |
| Единица продажи | J |
| Описание | P |
| Тип / назначение | R |
| Характеристики | V |
| Источник | W |
| Магазин | H |
| Дата / примечание | Y / Z |

C содержит дополнительную бизнес-группу, X повторяет название. Эти значения остаются в аудите.
Проверяются совпадение E/F без учёта регистра, совпадение G/X, формат URL/единицы и пустота неопределённых полей.
При несовпадении схема не применяется. Старой цены и точного остатка в этой раскладке нет.

## Идентичность и коммерческие данные

Полностью одинаковые 26 значений объединяются в одну запись с несколькими исходными номерами.
Разные явные артикулы поставщика из характеристик различают варианты с общим названием.
При неясности запись остаётся на review. Валидные уникальные SKU сохраняются.
Недостающие SKU и технические заполнители получают детерминированный REM-SHA256.
Предложения сравниваются с текущими SKU/slug БД; совпадающий товар не создаётся повторно.

Отсутствующая цена никогда не подменяется нулём. Дробная цена не округляется: Product.price — Int.
Отсутствующий остаток получает согласованный импортный ноль с STOCK_NOT_PROVIDED.
Текущий сайт показывает «Нет в наличии» и отключает покупку при stock <= 0.
Флаг означает неизвестный реальный остаток и хранится в отчёте; модель Product не имеет отдельного поля этого происхождения.

Каждая исходная категория имеет предложение, confidence и причину в semantic-category-mapping.md.
Только HIGH подставляется в Excel. MEDIUM/LOW остаются на review.
Для смешанной группы люстр разрешено построчное HIGH, когда конкретное название явно содержит «люстра».
Пустые бренды не заменяются названием поставщика или вымышленной маркой.

Все непустые значения характеристик сохраняются: пары нормализуются, свободные фрагменты переносятся в описание
с явной подписью источника. Противоречащие значения одного ключа блокируются для review.
Фото и ссылки не скачиваются; пустые изображения используют существующий placeholder.

## Dry-run очищенного файла

```powershell
npm run products:import -- --file reports/product-import/Remaro_products_cleaned.xlsx --sheet READY --report-dir reports/product-import/cleaned-ready
npm run products:import -- --file reports/product-import/Remaro_products_cleaned.xlsx --sheet MISSING_PRICE --report-dir reports/product-import/cleaned-missing-price
npm run products:import -- --file reports/product-import/Remaro_products_cleaned.xlsx --sheet MANUAL_REVIEW --report-dir reports/product-import/cleaned-manual-review
```

Отчёт READY не следует выдавать за результат всех 979 уникальных товаров.
Общая сводка: cleanup-summary.md; полный аудит: cleanup-audit.json.
Список всех товаров без цены (включая MANUAL_REVIEW): missing-prices.json.
Ни одна команда выше не разрешает применение. Производственный импорт требует отдельного разрешения.

Проверки: `python -B -X utf8 scripts/test-clean-products.py`,
`npx tsx --test scripts/product-import.test.ts`, lint, tsc --noEmit, build и git diff --check.
